# Oracle Notepad (Core Node 2.5) | Prestige HQ 🛠️
> *Официальный репозиторий проекта (мигрирован из `notepad-helper-2`).*

**Core Node 2.5** — это модульная среда разработки, интерактивный блокнот и виртуальный хаб для управления спецификациями миров, разработанный в рамках экосистемы *Prestige HQ*.

---

### 🚀 Основные возможности
* **Context Keeper:** Интегрированный блокнот с поддержкой форматирования и выезжающей панелью заметок для ведения концептов и мыслей по проекту. Все данные автоматически сохраняются в локальном кэше браузера.
* **Экспорт и импорт данных:** Мульти-форматный экспорт спецификаций (`.worldpack`, `.json`, `.txt`) и загрузка готовых пакетов на лету.
* **Oracle Chat & Agent:** Интеллектуальное ядро взаимодействия с переключением режимов («Диалог» / «Агент») для оперативного решения задач, генерации патчей и работы с кодом.
* **Mobile-First UX:** Адаптивная сетка, умный докинг панелей, кастомная клавиатура для кодинга с мобильных устройств и плавные шторки.

---

### 💬 Примеры фраз и запросов для Оракула
В зависимости от выбранного режима (Диалог или Агент), ты можешь использовать следующие паттерны для взаимодействия с системой:

* **Для кодинга и задач (Режим Агента):**
  * *«Напиши функцию валидации JSON-структуры для этого проекта»*
  * *«Сделай патч для оптимизации работы с localStorage»*
  * *«Исправь баг с отображением панели на мобильных устройствах»*
* **Для анализа и свободного общения (Режим Диалога):**
  * *«Объясни, как устроена архитектура этого модуля»*
  * *«Помоги составить план структуры нового мира (World 2)»*
  * *«Проведи ревью моих заметок и выдели ключевые идеи»*

### 🛠 Технологический стек
* **Frontend:** Чистый HTML5, CSS3 (CSS Grid / Flexbox), Vanilla JavaScript (ES6+).
* **UX/UI:** Material Symbols Rounded, динамическая палитра Material You, анимации сфер Оракула (Gooey effect).
* **Storage & Persistence:** LocalStorage для управления состоянием сессии и автосохранения кода.

---

### 📦 Быстрый старт
1. Клонируй репозиторий `oracle-notepad` или разверни файлы (`index.html`, `style.css`, `script.js`) на локальном сервере / хостинге.
2. Используйте левую панель для настройки метаданных проекта и прикрепления файлов.
3. Пиши код в центральной зоне кодинга (используй виртуальную клавиатуру для быстрой вставки спецсимволов `{ } [ ] ;`).
4. Обращайся к Оракулу в правой панели для генерации кода и управления агентом.
5. Выгружай готовые наработки через меню настроек в шапке.
